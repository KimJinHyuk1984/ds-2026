오리엔테이션과 Orange3·Colab 시작

1–3차시

이번 주는 Orange3와 Google Colab을 함께 준비합니다. 같은 데이터를 두 도구에서 확인하고, Orange3의 결과를 Python으로 재현하는 수업을 시작합니다.

현재는 설치·접속 안내를 볼 수 있습니다. CSV를 사용하는 실습은 준비 중입니다.

학습목표

  • Orange3와 Google Colab을 함께 열어 실습을 시작할 수 있다.
  • 따릉이 일별 대여 건수 CSV를 두 도구에서 불러와 같은 데이터를 확인할 수 있다.
  • 기본 워크플로우를 실행하며 데이터 과학의 활동을 살펴볼 수 있다.

Orange3 설치·실행

Windows 기준 안내입니다. 이미 설치되어 있으면 실행 단계부터 확인합니다.

  1. Orange 공식 다운로드 페이지(새 탭)를 엽니다.
  2. Windows의 Standalone installer를 내려받아 설치 화면의 안내에 따라 설치합니다. 다른 운영체제에서는 같은 페이지에서 맞는 설치 프로그램을 선택합니다.
  3. 설치가 끝나면 시작 메뉴나 설치된 바로가기에서 Orange를 실행합니다.
  4. 빈 작업 화면을 열어 왼쪽 위젯 목록과 가운데 작업 공간을 확인합니다. 현재는 내장 데이터와 예제 워크플로우를 불러오지 않습니다.
준비 확인

Orange의 빈 작업 화면이 열리면 설치·실행 준비가 끝났습니다. 따릉이 CSV를 연결하는 활동은 자료가 준비된 뒤 진행합니다.

조작 참고: Orange 시작 안내(새 탭)

Google Colab 접속·기본 사용

  1. Google Colab(새 탭)에 접속하고 수업에서 사용할 Google 계정으로 로그인합니다.
  2. 새 노트북을 만들고 제목을 week-01-ready.ipynb로 바꿉니다.
  3. 코드 셀에는 실행할 Python 코드를, 텍스트 셀에는 설명과 관찰 내용을 적습니다. 텍스트 셀에 ‘1주차 환경 준비’라고 적어 봅니다.
  4. 런타임을 연결하고 코드 셀에 아래 연결 확인 코드를 입력합니다. 셀 왼쪽 실행 버튼이나 Ctrl+Enter로 실행합니다.
print("Colab 준비 완료")
준비 확인

셀 아래에 ‘Colab 준비 완료’가 출력되는지 확인합니다. 이 코드는 실행 환경만 확인하며 CSV를 읽거나 데이터를 생성하지 않습니다.

노트북은 Google Drive에 저장됩니다. 이름과 저장 상태를 확인합니다. 런타임이 종료되면 실행 상태가 사라질 수 있으므로 다시 연결한 뒤 필요한 셀을 실행합니다.

조작 참고: Google Colab 공식 FAQ(새 탭)
