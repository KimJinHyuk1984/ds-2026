오리엔테이션과 Orange3·Colab 시작

1–3차시

따릉이 대여건수는 왜 날마다 다를까요? 서울의 353일을 Orange3로 살펴보고, 같은 결과를 Python으로 확인하며 데이터 과학을 시작합니다.

1차시 · 질문과 관찰 2차시 · Orange3 3차시 · Colab

이번 주의 목표

  • Orange3와 Google Colab을 함께 열어 실습을 시작할 수 있다.
  • 따릉이 일별 대여 건수 CSV를 두 도구에서 불러와 같은 데이터를 확인할 수 있다.
  • 기본 워크플로우를 실행하며 데이터 과학의 활동을 살펴볼 수 있다.

2차시 · Orange3

설치부터 표·분포·산점도까지 직접 연결합니다. 교사가 Python으로 그린 그래프와 비교합니다.

완성 코드를 실행해 같은 표와 산점도를 만듭니다. 변수와 조건을 바꾸어 결과를 비교합니다.

매 차시: 질문 제기 → Orange3에서 결과 확인 → 개념에 이름 붙이기 → Python으로 재현 → 결과 비교

01 질문 제기

“내일 따릉이를 타는 사람이 많을지, 무엇을 보고 판단할 수 있을까?”

각자 근거가 될 만한 정보를 하나 적어 봅니다. 날씨, 날짜처럼 이 파일에서 확인할 수 있는 정보와, 아직 없는 정보를 구분해 봅시다.

이 과목은 주 3차시씩 15주, 총 45차시입니다. Orange3에서 결과를 먼저 보고 Python으로 재현합니다. 6주차와 11주차의 미니 프로젝트를 거쳐 14~15주차에는 자신의 질문으로 분석합니다.

02 Orange3에서 결과 확인

교사는 File 불러오기와 Data Table 확인을 시연합니다. 아직 설치하지 않은 학생은 화면을 보며 다음을 찾습니다.

  • 353개의 행과 8개의 컬럼 이름을 확인합니다.
  • 서로 다른 두 날짜를 골라 평균기온과 대여건수를 읽습니다.
  • 대여건수가 날마다 같지 않다는 사실을 확인하고, 처음 적은 질문을 표로 살펴볼 수 있을지 말합니다.

03 개념에 이름 붙이기

데이터 과학은 질문에 답하기 위해 데이터를 모으고 정리하고 분석하여, 근거를 설명하는 활동입니다. 방금 우리는 질문에 필요한 기록을 찾고 비교하는 일을 했습니다.

이 표의 행은 관찰한 하루이고, 컬럼은 그날에 대해 기록한 속성입니다. 한두 날을 본 생각은 출발점입니다. 더 많은 날을 함께 살펴보고 생각이 맞는지 확인해야 합니다.

이번 주에는 표와 그래프를 살펴봅니다. 정리 방법, 통계, 예측 모델은 이후 주차에서 차례로 배웁니다.

Python 문법을 다시 배우는 시간이 아닙니다. 같은 파일을 다른 도구로 읽었을 때 같은 자료가 나타나는지에 집중합니다. 학생은 3차시에 이 코드를 직접 실행합니다.

한 행은 자전거 한 대나 대여소 한 곳이 아닙니다. 하루의 서울 전체 대여건수를 담고 있습니다.

한 번 불러온 파일을 표·분포·산점도 위젯에 각각 연결합니다.

01 질문 제기

“기온이 높은 날에는 따릉이 대여건수도 많을까?”

예상과 이유를 한 문장으로 적습니다. 353일을 한눈에 볼 방법을 생각해 봅시다.

02 Orange3에서 결과 확인

설치하고 빈 작업 화면 열기

  1. Orange 공식 다운로드(새 탭)에서 운영체제에 맞는 설치 프로그램을 받습니다. Windows는 Standalone installer를 선택합니다.
  2. 설치 안내에 따라 완료한 뒤 Orange를 실행하고 새 워크플로우를 엽니다. 이미 설치되어 있으면 여기서 시작합니다.
  3. 왼쪽 위젯 목록과 가운데 작업 공간을 찾습니다. 이 주차의 CSV를 내려받아 저장 위치를 확인합니다.

학교 PC에서 설치 권한이 필요하면 교사에게 요청합니다. 아래 실습에는 내려받은 bike-daily.csv를 사용합니다.

File · 데이터의 출발점

  1. Data 범주의 File 위젯을 작업 공간에 놓고 더블클릭합니다.
  2. 파일 열기 버튼으로 bike-daily.csv를 선택합니다. 한글 컬럼 이름과 데이터 정보가 나타나는지 확인합니다.
  3. 컬럼 설정에서 평균기온과 대여건수가 숫자형 Continuous인지 확인합니다. 필요하면 타입을 바꾸고 적용합니다.

글자가 깨지면 내려받은 원본 파일인지 확인하고, 가져오기 창의 인코딩 선택이 보이면 UTF-8로 설정합니다. 파일 내용을 고쳐 저장하기 전에 교사와 확인합니다.

세 위젯이 같은 전체 데이터를 받게 연결하기

FileData 출력
  • →
    Data TableData 입력 · 날짜별 값 확인
  • →
    DistributionsData 입력 · 대여건수 분포
  • →
    Scatter PlotData 입력 · 기온과 대여건수

위젯을 추가하고 File의 오른쪽 연결점에서 각 위젯의 왼쪽 연결점으로 끕니다. 연결 선택 창이 뜨면 Data → Data를 선택합니다.

세 연결선의 출발점은 모두 File입니다. Data Table의 선택된 행 출력을 사용하면 선택한 날짜만 그래프에 나타날 수 있습니다.

Data Table · 표에서 확인할 것

  1. Data Table을 열어 정보 영역에서 353개 데이터 행을 확인합니다.
  2. 가로로 살펴보며 날짜부터 대여건수까지 8개의 컬럼 이름을 확인합니다. 날짜나 요일은 별도 역할로 표시될 수 있어 Features 수만으로 전체 컬럼 수를 판단하지 않습니다.
  3. 날짜별 평균기온과 대여건수를 읽습니다. 강수량 컬럼에는 빈 값이 있다는 점만 관찰합니다.

Python의 처음 다섯 행과 비교할 때는 정렬을 원래대로 되돌리거나, 같은 날짜를 기준으로 비교합니다.

Distributions · 어느 구간에 날이 많이 모일까?

  1. Distributions를 열고 변수에서 대여건수를 선택합니다. Split by는 선택하지 않고 확률·누적 표시도 끕니다.
  2. 가로축은 대여건수 구간, 세로축은 그 구간에 속하는 날짜 수입니다. 가장 높은 막대가 있는 구간을 화면에서 읽어 기록합니다.
  3. Bin width를 바꾸어 막대의 모습을 비교합니다. 그래프 모습이 달라져도 원래 353일의 값은 같습니다.

이 데이터의 대여건수는 최소 14,293건, 최대 194,244건입니다. 한 날짜의 수치와 여러 날짜가 모인 모습은 어떻게 다른가요?

Scatter Plot · 353일을 점으로 보기

  1. Scatter Plot을 열고 X: 평균기온, Y: 대여건수로 설정합니다. 점 하나는 하루입니다.
  2. 색상과 크기는 변수별 구분 없이 일정하게 두고, Jittering은 0으로 설정합니다. 숫자형 지터 옵션도 끕니다. 회귀선은 켜지 않습니다.
  3. 차가운 날의 점들과 따뜻한 날의 점들을 비교합니다. 기온이 비슷해도 대여건수가 다른 점들을 찾아봅니다.

축에 컬럼이 없으면 File에서 평균기온·대여건수를 Continuous로, 역할을 Feature로 설정하고 다시 확인합니다.

관찰의 출발점: “기온이 높으면 대여가 많다.” 이 그림에서 전반적인 경향을 찾아 설명하되, 모든 날에 그대로 맞는 규칙인지도 점들을 보며 살펴봅니다.

03 개념에 이름 붙이기

워크플로우
데이터가 읽히고 표시되기까지의 작업과 연결입니다. 이번에는 File이 읽은 데이터를 세 위젯이 함께 받습니다.
분포
값들이 어느 구간에 얼마나 모여 있는지 나타낸 모습입니다. 막대 하나가 자전거 한 대를 뜻하지 않습니다.
산점도
두 수치의 짝을 점의 가로·세로 위치로 나타낸 그림입니다. 여기서는 하루의 평균기온과 대여건수가 한 점을 만듭니다.

04 Python으로 재현

교사는 CSV 읽기 → 한글 폰트 준비 → 산점도 코드를 차례로 실행하여 같은 두 축을 보여 줍니다. 학생은 Orange3 화면을 옆에 두고 비교합니다.

분포도 Python으로 확인합니다. 아래 셀은 CSV와 폰트 준비 셀을 실행한 뒤 사용합니다. bins=12는 화면을 나누는 구간 수이며 데이터의 측정값이 아닙니다.

plt.figure(figsize=(8, 5))
plt.hist(df["대여건수"], bins=12, edgecolor="white")
plt.xlabel("일별 대여건수 (건)")
plt.ylabel("날짜 수 (일)")
plt.title("353일의 따릉이 대여건수 분포")
plt.tight_layout()
plt.show()

05 결과 비교

  • 산점도는 두 도구 모두 평균기온이 가로축, 대여건수가 세로축인지 확인합니다. 축 눈금과 점 크기는 달라도 데이터의 위치 관계를 비교할 수 있습니다.
  • 분포의 막대 경계는 Bin width와 bins 설정에 따라 다를 수 있습니다. 가장 많이 모인 구간과 전체 범위를 비교합니다.
  • “기온이 높으면 대여가 많다”를 뒷받침하는 모습과, 기온만으로 설명하기 어려운 모습을 각각 기록합니다.

  4. 텍스트 셀에는 관찰과 비교 내용을 씁니다. 노트북의 저장 상태와 Google Drive의 저장 위치를 확인합니다.

셀 1 · 같은 CSV 읽기

파일 업로드 없이 배포 URL에서 읽습니다. 처음 다섯 행과 전체 크기를 확인합니다.

import pandas as pd
from IPython.display import display

DATA_URL = "https://kimjinhyuk1984.github.io/ds-2026/data/weather-bike/bike-daily.csv"
df = pd.read_csv(DATA_URL, encoding="utf-8-sig")
display(df.head())
print("행과 열:", df.shape)

확인 기준: 행과 열: (353, 8)과 한글 컬럼 이름이 표시되어야 합니다. head()는 전체 중 처음 다섯 행만 보여 줍니다.

셀 2 · 숫자와 빈 값 살펴보기

display(df.describe().round(1))
display(df.isna().sum().rename("빈 값 개수").to_frame())

describe()에서 mean은 평균, min과 max는 최소·최대입니다. 숫자형 컬럼의 요약을 보고 대여건수 최소 14,293, 최대 194,244와 평균기온 평균 15.0을 확인합니다.

두 번째 표에서는 강수량 200개, 다른 컬럼 0개의 빈 값을 확인합니다. 화면에서 빈 값이 NaN이나 ?로 보일 수 있습니다. 이번 주에는 관찰 내용만 기록합니다.

셀 3 · 한글이 네모로 보이지 않도록 준비하기

Colab 기본 환경에서는 Matplotlib의 한글이 깨질 수 있습니다. 아래 셀로 나눔 글꼴을 설치하고 현재 실행 환경의 Matplotlib에 등록합니다.

import subprocess
import matplotlib.pyplot as plt
from matplotlib import font_manager

subprocess.run(["apt-get", "-qq", "update"], check=True)
subprocess.run(["apt-get", "-qq", "install", "-y", "fonts-nanum"], check=True)
font_path = "/usr/share/fonts/truetype/nanum/NanumGothic.ttf"
font_manager.fontManager.addfont(font_path)
plt.rcParams["font.family"] = font_manager.FontProperties(fname=font_path).get_name()
plt.rcParams["axes.unicode_minus"] = False

이 셀은 Colab용입니다. 새 런타임에서는 다시 실행합니다. 네모가 계속 보이면 이 셀의 성공 여부를 확인한 뒤 그래프 셀을 다시 실행합니다. 설치가 실패하면 인터넷 연결과 오류 메시지를 확인해 재시도합니다.

비교 실험 B · 조건으로 날짜 고르기

새 코드 셀에서 실행합니다. holiday_value를 1과 0으로 바꾸어 선택한 날의 수와 그림을 비교합니다. 1일 때는 19일입니다.

holiday_value = 1
selected = df.loc[df["공휴일여부"].eq(holiday_value)]
print("선택한 날짜 수:", len(selected))

plt.figure(figsize=(8, 5))
plt.scatter(selected["평균기온"], selected["대여건수"], s=24, alpha=0.65)
plt.xlabel("평균기온 (°C)")
plt.ylabel("대여건수 (건)")
plt.title(f"공휴일여부 {holiday_value}인 날")
plt.xlim(df["평균기온"].min() - 2, df["평균기온"].max() + 2)
plt.ylim(0, df["대여건수"].max() * 1.05)
plt.tight_layout()
plt.show()

두 조건의 축 범위를 같게 두었습니다. 이 그림은 선택한 날짜만 보여 주므로 전체 353일의 그림과 구분합니다. 원래 df는 그대로이며 셀 4를 실행하면 전체 그림으로 돌아갑니다.

실행이 막혔을 때

  • df 또는 plt를 찾을 수 없음: 셀 1부터 순서대로 다시 실행합니다. 새 런타임에서는 앞서 실행한 상태가 사라질 수 있습니다.
  • URL을 읽지 못함: 셀 1의 전체 URL과 인터넷 연결을 확인합니다. 수업 사이트의 CSV 다운로드가 열리는지 확인합니다.
  • 한글이 네모로 표시됨: 셀 3이 오류 없이 끝났는지 확인하고 셀 4를 다시 실행합니다.
  • 353행이 아님: 다른 파일이나 일부 데이터인지 확인하고 셀 1의 배포 URL로 다시 읽습니다.
