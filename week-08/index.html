숫자 세 개로 분포를 그릴 수 있을까?

01 질문 제기

“평균 119,928건, 중앙값 126,749건, 표준편차 49,526건. 이 세 숫자만으로 날짜들이 어떻게 모였는지 알 수 있을까?”

어느 대여건수 구간에 날짜가 많이 모일지, 좌우가 비슷할지 먼저 간단히 예상해 봅니다. 7주차의 숫자와 이번 그래프에서 각각 알 수 있는 것을 구별합니다.

02 Orange3에서 결과 확인

  1. File에서 정제 CSV를 읽고 Data Table로 353행을 확인합니다. 평균기온·강수량·대여건수는 Numeric, 요일·공휴일여부는 Categorical로 둡니다.
  2. File → Distributions를 연결해 대여건수를 선택합니다. Fitted distribution은 None, Split by도 None으로 둡니다.
  3. Bin width를 바꿔가며 어느 구간에 날짜가 모이는지, 적은 값 쪽과 큰 값 쪽의 모양이 같은지 봅니다.
  4. File → Box Plot에서 대여건수, Subgroups=None, Annotated boxes를 선택해 평균·중앙값·박스와 양 끝을 확인합니다.

구간을 넓히면 세부 봉우리가 합쳐지고, 좁히면 작은 차이가 많이 드러납니다. 설정 하나의 모습만 보고 결론을 정하지 않습니다.

  • 날짜가 많이 모인 쪽과 꼬리가 이어지는 쪽은 어디인가?
  • 평균과 중앙값의 위치 차이가 분포와 어떻게 연결되는가?
  • 박스플롯만 보았을 때 히스토그램의 구간별 봉우리를 알 수 있는가?

그래프보여 주는 것읽을 때 주의
히스토그램값을 구간으로 묶고 각 구간의 날짜 수를 표시구간 너비를 확인합니다. 각 막대가 하루를 뜻하지 않습니다.
박스플롯중앙값·가운데 절반의 범위·수염 등으로 분포를 요약세부 봉우리와 빈 구간은 직접 드러나지 않습니다.

이 데이터는 큰 값 쪽에 날짜가 많이 모인 구간이 있고, 적은 값 쪽으로 꼬리가 이어져 좌우 대칭이 아닙니다. 평균이 중앙값보다 작다는 것은 그 모양을 살펴볼 단서이며, 숫자만으로 전체 모양을 확정할 수는 없습니다.

박스는 1사분위수부터 3사분위수까지, 가운데 선은 중앙값입니다. 평균 표식을 추가할 수도 있습니다. 박스 길이 자체가 표준편차는 아닙니다.

아래 Python 박스플롯은 기본적으로 박스 길이(IQR)의 1.5배 범위 안에 있는 관측값까지 수염을 그립니다. 도구마다 수염·표식 방식이 다를 수 있으므로 범례와 설정을 확인합니다. 별도 점으로 보인다는 이유만으로 오류라고 판단하거나 삭제하지 않습니다.

04 Python으로 재현

import pandas as pd

url = "https://kimjinhyuk1984.github.io/ds-2026/data/weather-bike/bike-daily-clean.csv"
bike = pd.read_csv(url, encoding="utf-8-sig", parse_dates=["날짜"])
rentals = bike["대여건수"]
print(bike.shape)
print(rentals.agg(["mean", "median", "std"]).round(2))

(353, 8)인지 확인합니다. std는 7주차와 같은 pandas 기본 기준입니다. 새 런타임에서는 준비 셀부터 다시 실행합니다.

같은 산점도에서 무엇을 더 읽을 수 있을까?

01 질문 제기

“1주차에 보았던 평균기온–대여건수 그림에서, 이제 어떤 근거를 읽을 수 있을까?”

그때는 점들을 보고 “기온이 높으면 대여가 많아 보인다”고 관찰했습니다. 이제는 축의 단위, 점 하나의 의미, 전체 경향과 퍼짐, 눈에 띄는 날짜를 나누어 설명합니다.

강수량과 대여건수, 요일별 대여건수로 바꾸면 어떤 모습일지도 예상합니다.

02 Orange3에서 결과 확인

  1. File → Scatter Plot을 연결해 x=평균기온, y=대여건수로 둡니다. Color·Size는 우선 별도 변수를 지정하지 않습니다.
  2. Jittering은 0으로, 회귀선은 꺼 둡니다. 전체적인 방향과 같은 기온에서의 세로 퍼짐을 확인합니다.
  3. x만 강수량으로 바꾸어 0mm 부근의 점 겹침과 비가 많은 날을 봅니다. 점 크기와 Opacity를 조절하며 확인합니다.
  4. x를 요일로 바꿉니다. 요일을 범주로 읽었는지, 표시 순서가 무엇인지 확인합니다.

점 하나는 하루입니다. 궁금한 점을 선택해 Selected Data → Data Table로 날짜를 확인합니다. 그림에서 점이 적어 보인다고 원본 날짜 수가 줄었다고 단정하지 않습니다.

03 개념에 이름 붙이기

산점도는 한 관측값의 두 속성을 가로·세로 위치로 함께 표시합니다. 전체 방향, 같은 x에서의 y 퍼짐, 따로 떨어진 점을 구별해 읽습니다.

“기온이 높은 쪽에 대여가 많은 날이 보인다”는 관찰과 “기온 때문에 늘었다”는 원인 설명은 다릅니다. 계절·강수·요일 같은 다른 조건도 함께 달라질 수 있습니다.

요일은 범주이므로 가로 간격이 수치 차이를 뜻하지 않습니다. 요일별 점 구름을 비교하고, 월요일에서 일요일까지의 기울기나 점을 잇는 선으로 해석하지 않습니다.

day_order = ["월", "화", "수", "목", "금", "토", "일"]

05 결과 비교

  • 평균기온이 높은 쪽에 큰 대여건수가 보이는 경향과, 같은 기온에서의 퍼짐을 두 도구에서 확인합니다. 언제나 계속 증가한다고 말할 수 있는지도 점검합니다.
  • 강수량 산점도의 0mm 점 겹침이 두 도구에서 같은가? 비가 많은 날과 적은 날을 선택해 실제 날짜를 확인합니다.

“축과 단위 → 전체 경향 → 예외나 퍼짐 → 그림만으로 말할 수 없는 것” 순서로 산점도를 설명합니다. 1주차의 첫 관찰보다 근거가 구체적이어야 합니다.

02 Orange3에서 결과 확인

  1. Scatter Plot을 평균기온–대여건수로 돌립니다. 전체를 본 뒤 일부 영역을 확대하고, 눈금과 화면 밖으로 나간 점을 확인합니다. Reset zoom으로 전체를 다시 봅니다.

  3. Size를 강수량으로 바꾸어 큰 점에 가려진 날짜가 있는지 봅니다. 다시 고정 크기로 되돌리고 Opacity를 조절해 비교합니다.

요일별 평균 막대는 요일별 하루 값들의 분포를 대신하지 않습니다. 합계·평균·날짜 수 중 무엇을 그리는지 제목과 축에 표시합니다.

막대의 길이로 크기를 비교할 때는 0 기준선이 중요합니다. 아래쪽을 잘라 표시하면 작은 차이도 큰 비율 차이처럼 보일 수 있습니다. 산점도에서 세부를 확대할 수는 있지만, 확대 범위와 화면 밖 데이터가 있음을 밝혀야 합니다.

  • 색: 범주를 구별하는 색과 수치가 커질수록 변하는 색을 구별합니다. 여러 그림을 비교할 때 색의 값 범위도 맞추고, 색만 의존하지 말고 범례·이름·필요한 모양을 함께 씁니다.
  • 크기: 큰 점이 다른 점을 가리지 않는지 확인합니다. 크기에 변수를 담으면 무엇을 나타내는지와 크기 기준을 범례로 밝혀야 합니다.

04 Python으로 재현

weekday_mean = bike.groupby("요일")["대여건수"].mean().reindex(day_order)
print(weekday_mean.round(1))

이제 요일마다 하나의 평균을 그립니다. 셀 7의 353개 점과 관측 단위가 다릅니다. 다음 두 그래프는 이 평균값을 똑같이 사용합니다.

limits = [(0, 140000), (90000, 140000)]
fig, axes = plt.subplots(1, 2, figsize=(12, 4), sharex=True)
for ax, ylim in zip(axes, limits):
    ax.bar(day_order, weekday_mean, color="steelblue")
    ax.set_ylim(*ylim)
    ax.set(xlabel="요일", ylabel="평균 대여건수(건)", title="요일별 평균 대여건수")
    ax.ticklabel_format(axis="y", style="plain", useOffset=False)
plt.tight_layout()
plt.show()

오해를 부르는 표현을 분석하기 위한 비교입니다. 왼쪽은 0, 오른쪽은 90,000건에서 시작합니다. 오른쪽만 보면 차이가 훨씬 커 보이지만 요일별 평균은 바뀌지 않았습니다.

오른쪽 하한을 50000·90000으로 바꿔 봅니다. 그래프를 공유할 때는 오해를 줄이는 축을 선택하고, 확대가 필요하면 범위를 설명합니다.

point_size = 24
plt.figure(figsize=(7, 4))
plt.scatter(bike["평균기온"], rentals, c=bike["강수량"], cmap="viridis",
            vmin=0, vmax=128.8, s=point_size, alpha=0.7, edgecolors="none")
plt.colorbar(label="강수량(mm)")
plt.xlabel("평균기온(°C)")
plt.ylabel("대여건수(건)")
plt.title("강수량을 색으로 표시한 평균기온–대여건수")
plt.tight_layout()
plt.show()

컬러바는 0~128.8mm를 같은 기준으로 표시합니다. point_size를 24·120으로 바꿔 점이 가려지는지 봅니다. 이 셀의 크기는 모든 점에 같아 추가 변수를 뜻하지 않습니다.

matplotlib의 s는 점의 면적을 정하는 값입니다. 지름을 두 배로 키우면 면적은 네 배가 되므로, 지름과 수치의 비례를 혼동하지 않습니다.

강수량처럼 0이 많은 값을 크기로 직접 쓰면 0인 날의 점이 사라질 수 있습니다. 크기 범례·최소 크기·겹침을 점검하고, 최소 크기를 더했다면 그 기준도 설명합니다. 복잡해지면 고정 크기와 색 표현만으로 질문에 답할 수 있는지 다시 생각합니다.
