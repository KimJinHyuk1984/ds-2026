산점도에서 본 관계를 숫자로 말할 수 있을까?

01 질문 제기

“평균기온·최고기온·최저기온·강수량 중 대여건수와 가장 뚜렷한 관계를 보이는 것은 무엇일까?”

8주차 산점도를 떠올리며 같은 방향인지 반대 방향인지, 점들이 직선 주변에 얼마나 모이는지 예상합니다. 기온 세 가지를 서로 비교하면 어떤 값이 나올지도 적습니다.

02 Orange3에서 결과 확인

  1. File에서 정제 CSV를 읽고 Data Table로 353행을 확인합니다. 기온 3종·강수량·대여건수는 모두 Numeric으로 둡니다.
  2. File → Select Columns에서 이 다섯 컬럼을 모두 Features에 둡니다. 대여건수도 이번 상관 비교에서는 Features에 넣고 Target은 비웁니다. 날짜는 Meta, 요일·공휴일여부는 이번 계산에서 제외합니다.
  3. Select Columns → Correlations를 연결하고 Pearson을 선택합니다. 대여건수가 포함된 네 쌍을 찾아 부호와 값을 기록합니다.
  4. 검색 필터를 비우고 기온끼리의 세 쌍도 기록합니다. 자기 자신과 비교한 값이나 같은 쌍을 뒤집은 것은 새 비교가 아닙니다.

Correlations의 Data → Scatter Plot의 Data, Features → Features를 연결합니다. 목록에서 한 쌍을 선택하고 산점도의 두 축을 확인합니다. 축이 반대라면 x=기상 변수, y=대여건수로 맞춥니다.

Jittering은 0, 회귀선은 끄고 전체 점을 봅니다. 기온끼리의 쌍도 선택해 얼마나 좁은 띠처럼 모이는지 확인합니다. 숫자가 큰 순서와 관계가 강한 순서를 구별해 봅니다.

03 개념에 이름 붙이기

이번 주에 사용하는 Pearson 상관계수
값읽는 방법
0보다 큼한 값이 큰 쪽에 다른 값도 큰 관측이 모이는 양의 선형 관계
0보다 작음한 값이 큰 쪽에 다른 값은 작은 관측이 모이는 음의 선형 관계
절댓값이 1에 가까움양 또는 음의 직선 관계가 뚜렷함
0에 가까움직선 관계가 약함. 곡선 등 다른 관계가 없다는 뜻은 아님

상관계수 r의 범위는 −1~1이며 단위가 없습니다. 두 변수가 변하는 자료에서 정확히 직선 위에 놓이면 1 또는 −1입니다. 양·음은 방향, 절댓값은 선형 관계의 강도를 나타냅니다.

r=0.6170을 “기온 때문에 대여가 61.70% 늘었다”거나 “예측이 61.70% 정확하다”고 읽지 않습니다. 두 컬럼이 함께 변하는 모습을 요약한 값입니다.

평균기온·최고기온·최저기온의 상관이 높으면 세 컬럼이 비슷한 정보를 많이 담고 있다는 단서입니다. 높은 상관만으로 원인이나 사용할 입력 변수를 자동으로 결정하지 않습니다.

04 Python으로 재현

import pandas as pd

url = "https://kimjinhyuk1984.github.io/ds-2026/data/weather-bike/bike-daily-clean.csv"
df = pd.read_csv(url, encoding="utf-8-sig", parse_dates=["날짜"])
features = ["평균기온", "최고기온", "최저기온", "강수량"]
columns = features + ["대여건수"]
print(df.shape)
print(df[columns].isna().sum())

(353, 8)과 다섯 컬럼의 빈 값 0개를 확인합니다. 날짜·요일·공휴일여부를 포함한 전체 표에 바로 corr를 적용하지 않고 비교할 수치 컬럼을 정합니다.

correlations = df[columns].corr(method="pearson")
with_rentals = correlations.loc[features, "대여건수"]
print(with_rentals.round(4))

각 값의 부호와 절댓값을 비교합니다. 계산은 소수 전체로 하고 표시만 소수 넷째 자리로 반올림합니다. 가장 큰 양의 값과 절댓값이 가장 큰 값을 찾아봅니다.

temperatures = ["평균기온", "최고기온", "최저기온"]
print(correlations.loc[temperatures, temperatures].round(4))

대각선의 1은 자기 자신과의 비교입니다. 표의 위아래에 반복되는 쌍을 한 번씩만 읽으면 서로 다른 비교는 세 개입니다.

함께 늘었다면 원인이라고 말해도 될까?

01 질문 제기

“기온이 높은 날 대여가 많다. 그렇다면 기온을 높이기만 하면 대여가 늘어날까?”

기온이 활동하기 좋은 환경을 만들 수도 있습니다. 계절에 따라 기온과 낮의 길이·야외 활동이 함께 달라질 수도 있습니다. 현재의 두 컬럼만으로 어느 설명이 맞는지 구별할 수 있을까요?

“기온이 높으면 언제나 더 많이 빌린다”는 주장에 맞지 않는 날짜부터 스스로 찾아봅니다.

02 Orange3에서 결과 확인

  1. File에서 새 Select Rows를 연결하고 평균기온을 20 이상 21 이하로 제한합니다. Matching Data를 Data Table과 Scatter Plot으로 보냅니다.
  2. 날짜·요일·강수량·대여건수를 함께 봅니다. 기온은 비슷한데 대여가 서로 다른 두 날짜를 찾아 기록합니다.
  3. Scatter Plot에서 x=평균기온, y=대여건수, Color=강수량으로 보고 범례를 확인합니다. 같은 기온에서도 세로로 퍼지는 점을 봅니다.

발견한 날짜에서 무엇이 같고 무엇이 다른지 구별합니다. 비가 오는지·요일이 같은지를 확인하되 차이의 원인을 곧바로 한 가지로 확정하지 않습니다.

이번에는 Select Rows의 기온 조건을 지우고 날짜를 2024-08-01~2024-08-31로 둡니다. Matching Data에서 31행을 확인합니다.

이 결과를 Select Columns → Correlations로 연결하고 25차시와 같은 다섯 Numeric Features·Pearson 설정을 사용합니다. 평균기온–대여건수 값을 전체 353일 결과와 비교합니다.

날짜 범위를 좁히면 관찰하는 기온 범위와 날씨·활동 조건도 달라집니다. 전체 자료와 한 달의 숫자가 같은 결론을 주는지 살펴봅니다.

03 개념에 이름 붙이기

상관관계는 두 변수가 함께 변하는 모습입니다. 인과관계는 한 요인을 바꾸는 것이 다른 결과의 변화를 일으키는 관계입니다. 관찰 자료의 상관만으로 그 원인을 확정할 수는 없습니다.

계절 같은 제3의 요인이 기온과 야외 활동 모두와 관련될 수 있습니다. “기온의 영향”과 “계절에 함께 달라진 다른 조건의 영향”은 이 상관계수 하나로 분리되지 않습니다.

반례가 있다는 것은 “언제나 더 많다”는 주장을 되돌아볼 근거입니다. 반례 하나가 기온의 영향이 전혀 없다는 증거가 되는 것은 아닙니다.

“아이스크림 판매량과 익사 사고가 함께 늘어난 자료를 보았다고 가정하자. 아이스크림을 먹어서 사고가 늘었다고 결론 내릴 수 있을까?”

두 현상에 함께 관련될 조건을 모둠에서 먼저 제시합니다. 이 활동은 설명을 검토하는 생각 실험이며 별도의 데이터나 상관계수를 만들지 않습니다.

같은 방식으로 생활 속 예를 하나 더 만들고 ① 함께 변할 두 항목 ② 가능한 제3의 요인 ③ 원인인지 확인하려면 더 필요한 자료를 적습니다.

04 Python으로 재현

low, high = 20, 21
near = df.loc[df["평균기온"].between(low, high),
              ["날짜", "요일", "평균기온", "강수량", "대여건수"]]
print(len(near))
print(near.sort_values("대여건수").to_string(index=False))

기본 범위는 16일입니다. low·high를 바꾸어 다른 날짜 쌍도 찾아봅니다. 코드 결과에서 두 행을 골라 “기온만으로 설명하기 어려운 점”을 적습니다.

month = 8
part = df.loc[df["날짜"].dt.month.eq(month), ["평균기온", "대여건수"]]
print("선택한 달의 날짜 수:", len(part))
print("전체:", correlations.loc["평균기온", "대여건수"].round(4))
print("선택한 달:", part.corr(method="pearson").loc["평균기온", "대여건수"].round(4))

이 파일에서 month=8은 2024년 8월의 31개 날짜를 뜻합니다. month를 5·9 등으로 바꾸고 선택 일수와 값을 함께 비교합니다. 기간에 따른 차이를 보는 활동이며, 계절의 인과 효과를 따로 계산한 것은 아닙니다.

대여건수를 예측하는 직선을 고를 수 있을까?

01 질문 제기

“기온을 하나 알려 주면 대여건수를 어느 정도로 예측할까? 산점도 위에 직선 하나를 긋는다면 어디가 좋을까?”

친구와 각각 선을 고른 뒤 비교합니다. 눈대중으로 보기 좋은 선이 같은지, 어느 선이 더 낫다는 판단의 근거가 무엇인지 이야기합니다.

02 Orange3에서 결과 확인

  1. 기간·기온 필터를 거치지 않은 전체 353행을 Scatter Plot으로 연결합니다. x=평균기온, y=대여건수, Color·Size는 고정, Jittering=0으로 둡니다.
  2. 회귀선 자동 표시를 끈 채 자기 산점도를 보고 종이에 축과 점 구름을 간단히 옮깁니다. 그 위에 직선 하나를 눈대중으로 그립니다. 자기 그래프를 화면 캡처해 선을 표시해도 됩니다.
  3. 같은 x에서 직선의 높이를 예측값으로 읽습니다. 실제 점이 선 위·아래에 있을 때 얼마나 떨어져 있는지 봅니다.

두 날짜를 골라 선의 높이와 실제 값을 비교합니다. 한 날짜를 잘 맞추려고 선을 옮기면 다른 날짜는 어떻게 되는지 확인합니다.

03 개념에 이름 붙이기

따릉이 예측에서 각 값의 역할
말이번 활동에서의 뜻
입력예측에 사용할 평균기온(°C)
회귀 모델입력을 받아 대여건수 같은 수치 값을 예측하는 규칙
예측값직선에서 해당 기온에 대응하는 높이(건)
실제 값그 날짜에 기록된 대여건수(건)
오차이 수업에서는 실제 값 − 예측값. 그림에서는 같은 x의 세로 차이

이번에는 직선을 하나의 규칙으로 사용해 봅니다. 같은 기온이면 같은 예측을 하지만 실제 대여건수는 서로 다를 수 있습니다.

오차가 양수이면 실제 값이 예측보다 크고, 음수이면 예측이 실제보다 큽니다. 부호만 보지 않고 얼마나 떨어졌는지도 봅니다.

어떤 날짜만 잘 맞는 선과 여러 날짜를 두루 가깝게 지나는 선 중 무엇을 고를까요? 친구와 같은 자료를 보고도 판단이 다르다면 여러 날짜의 오차를 비교할 공통 기준이 필요합니다.

오늘은 입력·예측·오차와 기준의 필요성까지 확인합니다. 데이터를 이용해 직선을 고르는 학습 방법은 10주차에서 다룹니다.

04 Python으로 재현

dates = pd.to_datetime(["2025-01-10", "2024-06-01"])
picked = df.set_index("날짜").loc[dates, ["평균기온", "대여건수"]].copy()
picked["예측값"] = [50000, 150000]
print(picked)

두 기온은 실제 날짜의 값입니다. 50,000건·150,000건은 선을 그려 보기 위해 정한 활동용 예측값입니다. 앞서 눈대중으로 고른 높이에 맞게 바꿉니다. CSV는 그대로 두고 노트북의 사본에서만 예측값을 표시합니다.

fig, ax = plt.subplots(figsize=(8, 4))
ax.scatter(df["평균기온"], df["대여건수"], s=18, alpha=0.35, label="실제 353일")
ax.plot(picked["평균기온"], picked["예측값"], "o-", color="tab:red", label="내 직선 후보")
ax.vlines(picked["평균기온"], picked["대여건수"], picked["예측값"],
          colors="black", linestyles="--", label="두 날짜의 차이")
ax.set(xlabel="평균기온(°C)", ylabel="대여건수(건)", title="직선 후보와 실제 값")
ax.legend()
plt.tight_layout()
plt.show()

코드는 여러분이 정한 두 지점을 잇습니다. 선분은 두 기온 사이 구간에만 그려집니다. 검은 점선은 선택한 날짜의 실제 값과 예측값 사이의 세로 차이입니다. 친구의 두 예측값으로 셀 8~9를 다시 실행해 선을 비교합니다.

picked["오차(실제-예측)"] = picked["대여건수"] - picked["예측값"]
print(picked[["평균기온", "대여건수", "예측값", "오차(실제-예측)"]])

기본 예측값에서는 2025-01-10의 오차가 4,566건, 2024-06-01은 17,881건입니다. 예측값을 60,000·180,000으로 바꾸고 셀 8~10을 다시 실행해 오차의 부호와 거리가 어떻게 달라지는지 확인합니다.

05 결과 비교

  • Orange3에서 본 점 구름과 Python의 전체 점 위치가 같은가? 손으로 고른 선의 높이를 코드로 다시 표시했는가?
  • 한 날짜의 예측을 실제 값에 가깝게 옮기면 다른 날짜도 함께 좋아지는가?
  • 셀 10은 두 날짜만 계산했다. 이 두 오차가 작다고 나머지 351일도 잘 맞는다고 말할 수 있는가?
  • 다른 날짜들까지 함께 판단하려면 무엇을 비교해야 할까? 모둠의 “좋은 직선” 기준을 한 문장으로 제안한다.

예측을 만들 수 있다는 것과 그 원인을 설명할 수 있다는 것도 구별합니다. 기온으로 대여건수를 예측하는 규칙을 만들었다고 기온의 인과 효과가 증명되지는 않습니다.
