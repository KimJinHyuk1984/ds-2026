평균은 하루의 대여를 잘 대표할까?

01 질문 제기

“평균은 119,928건인데, 가운데 날짜의 값은 126,749건이다. 왜 평균이 더 작을까?”

여기서 가운데는 대여건수를 작은 값부터 정렬했을 때의 가운데입니다. 날짜순 가운데와 다릅니다. 적게 대여한 날들이 어느 시기에 모이는지 먼저 예상합니다.

02 Orange3에서 결과 확인

  1. File로 bike-daily-clean.csv를 읽고 Data Table에서 353행을 확인합니다. 대여건수·강수량은 Numeric, 날짜는 Time, 요일은 Categorical로 읽습니다.
  2. File → Feature Statistics를 연결해 대여건수의 Mean·Mode·분포를 봅니다. 설치 버전에서 이름이 Column Statistics로 보이면 같은 역할의 위젯을 사용합니다.
  3. File → Box Plot도 연결합니다. 대여건수, Subgroups는 None, Annotated boxes를 선택해 평균과 중앙값을 비교합니다.

Feature Statistics의 Dispersion은 분산 자체가 아닙니다. 숫자 속성에서는 표준편차를 평균으로 나눈 값이므로, 분산·표준편차는 아래 Python 결과와 구별해 읽습니다.

  1. Data Table에서 대여건수를 오름차순 정렬하고 낮은 값의 날짜를 봅니다.
  2. File → Select Rows에서 날짜를 2024-12-01 이상, 2025-02-16 이하로 설정합니다. Matching Data → Feature Statistics와 Data Table을 연결합니다.
  3. 전체 평균과 겨울 기간 평균을 적고, 강수량의 전체 Mean도 확인합니다. 필터 조건과 행 수를 함께 기록합니다.

겨울만 보았을 때 평균이 어떻게 달라지는지 확인합니다. 낮은 날이 모두 겨울인지는 별도로 점검합니다.

기술통계는 가지고 있는 데이터를 숫자와 그림으로 요약하는 일입니다. 평균 하나가 모든 날짜의 모습을 보여 주지는 못합니다.

분산과 표준편차

분산은 각 값이 평균에서 떨어진 정도를 제곱해 요약한 값입니다. 표준편차는 분산의 제곱근으로, 원래 데이터와 같은 단위에서 퍼짐을 읽게 해 줍니다.

대여건수의 분산은 건², 표준편차는 건입니다. 서로 다른 두 집단을 비교할 때는 단위와 계산 기준을 맞춥니다. 작은 표준편차는 값들이 평균 주변에 더 모여 있음을 뜻합니다.

04 Python으로 재현

import pandas as pd
from IPython.display import display

url = "https://kimjinhyuk1984.github.io/ds-2026/data/weather-bike/bike-daily-clean.csv"
bike = pd.read_csv(url, encoding="utf-8-sig", parse_dates=["날짜"])
print(bike.shape)
display(bike.head())

(353, 8)인지 확인합니다. 새 런타임에서는 이 셀부터 다시 실행합니다.

x = bike["대여건수"]
display(x.describe().round(2))
print("평균:", round(x.mean(), 2))
print("중앙값:", x.median())
print("분산(pandas 기본):", round(x.var(ddof=1), 2))
print("표준편차(pandas 기본):", round(x.std(ddof=1), 2))

count는 값의 개수, mean은 평균, 50%는 중앙값, std는 표준편차입니다. describe()에 없는 분산은 따로 출력했습니다. 셀 2의 컬럼을 평균기온으로 바꿔 단위와 값을 비교한 뒤, 셀 3부터는 대여건수로 되돌려 셀 2를 다시 실행합니다.

counts = x.value_counts()
print("대여건수 한 값의 최대 등장 횟수:", counts.max())
if counts.max() == 1:
    print("모두 한 번씩 나와 두드러진 최빈값이 없습니다.")
else:
    print("대여건수 최빈값:", x.mode().tolist())
display(bike["요일"].value_counts())
print("요일 최빈값:", bike["요일"].mode().tolist())

대여건수는 353개 값이 모두 다릅니다. 도구가 Mode로 하나를 표시해도 대표하는 값 하나가 있다는 뜻은 아닙니다. 요일처럼 반복되는 값과 비교합니다.

winter = bike["날짜"].dt.month.isin([12, 1, 2])
by_season = bike.assign(구분=winter.map({True: "겨울(12~2월)", False: "그 외"}))
display(by_season.groupby("구분")["대여건수"]
        .agg(["count", "mean", "median"]).round(1))
display(bike.nsmallest(5, "대여건수")[["날짜", "대여건수", "강수량"]])
print("처리 후 강수량 평균(mm):", round(bike["강수량"].mean(), 2))

겨울 78일의 낮은 값이 전체 평균에 어떻게 반영되는지 봅니다. 가장 낮은 날의 날짜·강수량도 확인해, 계절만으로 모든 저조일을 설명하지 않습니다.

05 결과 비교

  • 두 도구의 대여건수 평균 약 119,928건과 중앙값 126,749건을 대조합니다.
  • 겨울 78일의 평균은 약 61,294건, 나머지 275일은 약 136,558건입니다. 겨울의 낮은 값들이 전체 평균을 끌어내리는 근거로 설명합니다.
  • 최저일은 2024-05-05입니다. 겨울 저조일 외에도 평균에 영향을 주는 날들이 있습니다.

값의 범위와 기간을 확인한 뒤, “평균이 중앙값보다 작다”를 실제 날짜들의 특징과 연결해 씁니다. 원인을 한 가지로 확정하지 않습니다.

print("pandas 기본(n-1):", x.std(ddof=1))

이 페이지의 49,526건은 pandas 기본값처럼 제곱한 차이의 합을 n−1로 나눠 계산한 표준편차입니다. 353개 전체를 n으로 나눈 기준은 약 49,455건이며 Orange3 Box Plot과 대조할 때 사용합니다. 공식 유도보다 어떤 기준인지 표시하는 데 집중합니다.

월별로 나누면 더 비슷해질까?

01 질문 제기

“평균이 약 12만 건인데, 표준편차는 약 5만 건이다. 매일 비슷하게 대여한다고 말할 수 있을까?”

대여건수의 표준편차 49,526건은 평균의 약 41.3%입니다. 서로 다른 계절을 한꺼번에 보아서 퍼짐이 커졌을지, 같은 달 안에서도 차이가 클지 예상합니다.

02 Orange3에서 결과 확인

  1. File에서 전체 데이터용 Box Plot과 Distributions를 연결합니다. 두 위젯 모두 대여건수를 선택합니다. Box Plot은 Annotated boxes, Distributions의 Fitted distribution은 None으로 둡니다.
  2. File → Select Rows에서 날짜 범위를 한 달로 고릅니다. Matching Data → 별도의 Box Plot·Distributions·Data Table을 연결합니다.
  3. 먼저 2025-01-01~01-31, 다음은 2024-05-01~05-31로 바꾸어 봅니다. 각각 31행인지 확인하고 전체와 비교합니다.

두 분포의 가로축 범위와 Bin width를 맞춰 비교합니다. 도구가 자동으로 축을 바꾸면 눈금 수치를 먼저 읽습니다. 서로 다른 행 수 때문에 막대 높이만으로 퍼짐을 판단하지 않습니다.

Box Plot에서는 평균과 중앙값의 위치, 박스와 전체 범위를 관찰합니다. 박스의 폭은 가운데 절반의 퍼짐이며 표준편차와 같은 값은 아닙니다.

  • 겨울 한 달의 퍼짐이 전체보다 줄었는가?
  • 2024년 5월도 같은가? 낮은 값과 높은 값이 함께 있는가?
  • 한 달을 바꿀 때마다 행 수·가로축 범위·통계량을 함께 기록했는가?

다른 달도 확인하되 2025년 2월은 16일까지 16일만 포함합니다.

03 개념에 이름 붙이기

분포는 값들이 어느 구간에 얼마나 모여 있는지를 보여 주고, 산포는 그 값들이 퍼진 정도를 말합니다. 평균이 같아도 산포는 다를 수 있습니다.

전체의 산포에는 계절별 평균 차이와 같은 달 안의 날짜별 차이가 함께 반영됩니다. 월별로 나누면 전자의 영향을 줄여 관찰할 수 있지만, 모든 달의 표준편차가 반드시 작아지는 것은 아닙니다.

표준편차는 최대 차이도, 모든 날짜가 반드시 들어가는 범위도 아닙니다. “평균±표준편차 밖이면 오류”로 해석하지 않습니다.

month_key = bike["날짜"].dt.strftime("%Y-%m")
monthly = bike.groupby(month_key)["대여건수"].describe()
display(monthly.round(2))
overall_std = bike["대여건수"].std()
print("전체 표준편차:", round(overall_std, 2))
display(monthly.loc[monthly["std"] > overall_std, ["count", "mean", "std"]])
print("평균 대비 표준편차(%):",
      round(overall_std / bike["대여건수"].mean() * 100, 1))

날짜에서 연·월을 묶는 기준을 만들어 groupby().describe()로 요약합니다. 원본 CSV에 새 컬럼을 저장하지 않습니다. 마지막 표에는 전체보다 표준편차가 큰 달만 나옵니다.

month = "2024-05"

30일만 보고 353일을 추측할 수 있을까?

01 질문 제기

“353일 중 30일만 골라 평균을 구하면 전체 평균과 같을까? 다시 고르면 어떻게 될까?”

이번 실습에서는 파일의 353일 전체를 알고 있습니다. 일부 날짜만 볼 수 있는 상황을 만들어 그 값으로 전체를 추측한 뒤, 알고 있는 전체 평균과 비교합니다.

02 Orange3에서 결과 확인

  1. 월별 Select Rows를 거치지 않은 File의 353행을 Data Sampler에 연결합니다.
  2. Fixed sample size = 30으로 설정합니다. Sample with replacement, Replicable sampling, Stratify sample은 모두 해제합니다.
  3. Data Sample 출력을 Data Table과 Feature Statistics에 연결합니다. Remaining Data 출력과 구별합니다.
  4. Sample Data를 눌러 30행과 대여건수 평균을 기록합니다. 같은 크기로 다섯 번 뽑아 평균이 어떻게 달라지는지 봅니다.

원본 File → Feature Statistics도 따로 연결해 353일 전체 평균을 비교 기준으로 둡니다.

Fixed sample size를 30 → 100 → 200으로 바꾸고 각각 다섯 번 뽑습니다. 한 번에 선택된 날짜는 중복되지 않지만, 다음 추출에서는 이전에 뽑혔던 날짜가 다시 나올 수 있습니다.

전체 평균에서 가장 멀었던 결과와 가까웠던 결과를 적습니다. 한 번의 결과만 보고 결론을 내리지 않습니다. 표본 평균이 계속 같으면 Replicable sampling 해제와 Sample Data 재실행을 확인합니다.

03 개념에 이름 붙이기

이번 실습의 범위
이름이번 실습에서의 의미
모집단알아보려는 전체: 이 파일의 353일
표본모집단에서 일부 뽑은 날짜들: 예를 들어 30일

추론통계표본에서 구한 통계량으로 모집단의 특성을 추측하는 일

뽑힌 날짜가 달라지면 표본 평균도 달라집니다. 같은 크기로 반복해 보고, 크기를 늘렸을 때 결과들이 얼마나 모이는지 관찰합니다.

여기서 모집단은 2024-03-01~2025-02-16의 353일입니다. 따릉이가 운영된 모든 과거와 미래 날짜를 뜻하지 않습니다.

모든 날짜가 뽑힐 기회를 갖도록 무작위로 고릅니다. 겨울만 편의대로 고르면 표본이 커져도 전체 계절을 반영하기 어렵습니다. 표본 크기와 뽑는 범위를 함께 확인해야 합니다.

04 Python으로 재현

population = bike["대여건수"]
n = 30
sample = population.sample(n=n, replace=False)
display(sample.head())
print("표본 날짜 수:", len(sample))
print("표본 평균:", round(sample.mean(), 1))
print("353일 전체 평균:", round(population.mean(), 1))

먼저 n = 30으로 같은 셀을 다섯 번 실행합니다. 이어 100, 200으로 바꿉니다. 표본마다 값이 달라질 수 있으므로 특정 출력 숫자를 정답으로 외우지 않습니다.

sizes = [30, 100, 200]
repeats = 100
seed_start = 0
means = pd.DataFrame({
    n: [population.sample(n=n, replace=False, random_state=seed_start + i).mean()
        for i in range(repeats)]
    for n in sizes
})
means.columns.name = "표본 크기(일)"
display(means.head().round(1))

표의 한 행은 한 번씩 뽑은 결과이며, 각 열에는 해당 크기의 평균이 100개 들어갑니다. repeats는 반복 횟수이고 표본 크기와 다릅니다.

random_state에는 반복마다 다른 값을 넣었습니다. 같은 seed_start로 다시 실행하면 같은 실험을 대조할 수 있고, seed_start = 1000으로 바꾸면 다른 추출 결과를 살펴볼 수 있습니다.

비교할 때는 셀 10을 실행한 뒤 셀 11~12를 다시 실행합니다. Orange3와 Python은 추출 방식이 달라 같은 날짜나 평균이 뽑혀야 하는 것은 아닙니다.

summary = pd.DataFrame({
    "반복 평균들의 평균": means.mean(),
    "가장 작은 표본 평균": means.min(),
    "가장 큰 표본 평균": means.max()
})
display(summary.round(1))
print("353일 전체 평균:", round(population.mean(), 1))

같은 100번 반복에서 작은 평균과 큰 평균 사이가 어떻게 달라지는지 읽습니다. 이 범위는 이번에 실제로 뽑은 결과들의 범위입니다.

ax = means.plot.box(figsize=(7, 4))
ax.axhline(population.mean(), color="red", linestyle="--", label="353일 전체 평균")
ax.set(xlabel="한 번에 뽑은 날짜 수(일)", ylabel="표본 평균 대여건수(건)",
       title=f"각 크기에서 {repeats}번 뽑은 표본 평균")
ax.legend()
plt.tight_layout()
plt.show()

각 상자는 하루 대여건수가 아니라 100개의 표본 평균을 요약합니다. 같은 세로축에서 30·100·200일 표본 평균들의 퍼짐을 비교합니다.

05 결과 비교

  • 두 도구 모두 같은 크기의 표본을 다시 뽑으면 평균이 달라질 수 있는가?
  • 표본 크기를 늘렸을 때 여러 평균이 전체 평균 주변에 더 모이는 경향이 보이는가?
  • 한 번의 200일 표본이 모든 30일 표본보다 반드시 가까웠는가, 아니면 반복 결과의 전체 모습을 봐야 하는가?

표본으로 모집단을 추측하는 것이 추론통계입니다. 표본이 커질수록 무작위 추출 결과의 흔들림은 대체로 줄지만, 한 번의 결과가 항상 더 가까운 것은 아닙니다. 뽑은 범위도 맞아야 합니다.
