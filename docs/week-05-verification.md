파생변수의 키는 학교코드+급식일자+식사종류다. 급식인원을 메뉴별로 합산하지 않는다. 번호 미표기는 성분 부재가 아니라 표시 상태로 해석한다. 메뉴 비중과 급식 등장률의 분모를 구분하고, 후자는 같은 급식의 같은 메뉴를 한 번만 센다. 비율로 바꿔도 식사·기간·이름 표기 차이가 남는다고 설명했다.

## 생성기 검토와 한계

- 원본 필수 컬럼·행 수·키·날짜·인원·빈 값을 검증한다. 한 급식의 여러 메뉴로 확장하며 원본 순서와 메타데이터를 유지한다.
- 끝의 숫자 괄호만 범위 확인 후 추출한다. 다른 괄호·숫자·별표·내부 공백은 보존하고, 번호는 쉼표 문자열로 출력한다.
- 비표준 태그·숫자 목록·괄호·빈 메뉴·모호한 중간 번호 후보는 위치와 원문을 출력하고 저장을 중단한다. 오류 행을 제외한 일부 CSV를 배포하지 않는다.
- 원본 경로/파일로 쓰지 않으며 기본적으로 기존 결과를 덮어쓰지 않는다. UTF-8 BOM·표준 CSV 인용·인덱스 없음이다.
- 미래 자료의 끝에 1~19 범위 숫자 설명이 나타나면 오인 가능성이 있다. 원문 검토와 별도 예외 정책이 필요하다. 현재 데이터 외 정확도를 주장하지 않는다.
- 생성 스크립트 실행·함수 import·Python 구문 컴파일·Colab 셀 실행은 **미실행**이다. 원문 사전 점검과 소스 검토를 실행 통과로 표현하지 않는다.
