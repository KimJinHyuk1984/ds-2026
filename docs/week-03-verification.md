# 3주차 완성·검증 기록

2026-09-10. 사용자 2주차 검증 완료와 3주차 작성 승인을 근거로 진행했다. 대상은 7~9차시, 데이터는 schools.csv·meals.csv·bike-daily.csv이며 교재 참조는 p.23·p.29이다.

## 작성 결과

- 7차시: 12개월 따릉이 원본 38,286,211행 → 일별 353행을 소재로 처리 비용·집계의 정보 손실·빅데이터·데이터베이스/DBMS·데이터셋을 설명한다. 원본 행 수는 사용자 확정 수치이며 이번에 원본을 재계수하지 않았다.
- 8차시: meals를 동양 302·명덕 743·영일 300·세현 159행으로 나누고 Concatenate/pd.concat으로 복원한다. 명덕+세현 선택 결과는 902행이다. 식사 종류 차이가 있어도 원본 12열이 같고 빈 값이 없으므로 재결합에 새 결측은 없다. 식사 조합에 해당하는 행이 없는 것과 빈 셀을 구별한다.
- 사용자에게 원본 재결합 유지/학교별 식사 요약표 확장 선택을 비동기 질문으로 제시했다. 응답을 받지 않은 상태에서 권장한 원본 재결합 구성으로 진행했다. 원본과 다른 결과를 만들기 위해 컬럼을 없애거나 빈 값을 삽입하지 않았다.
- 9차시: 학교 정보의 다대일 left merge, 동양·세현 중식의 날짜 inner/left/outer, 입력 방향 변경, 기상·따릉이 날짜 재결합을 작성했다. 학교 정보는 오른쪽 코드가 유일하고, 날짜 비교는 양쪽 중식 날짜가 유일하다. Orange3의 각 Merge Data 모드 이름과 독립 Concatenate 위젯의 차이를 설명한다.
- 학습 경계: 결측 채우기·행 삭제·메뉴 텍스트 분리는 제공하지 않는다. 기상 재결합에 기존 강수량 빈 값 200개가 남는다는 관찰까지만 한다. 보충 그래프는 koreanize-matplotlib 설치/import를 한 셀에 두고 기본 발표에서 제외했다.

PowerShell Import-Csv로 현재 배포 CSV를 읽어 날짜 집합과 연결 값을 검토했다. Python 코드를 실행한 결과로 표시하지 않는다.
