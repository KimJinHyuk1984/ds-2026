## 코드 검토

- 수집기 인증키는 NEIS_API_KEY 환경변수 또는 getpass 숨김 입력에서만 읽는다. sample·빈 값·자리표시자 키를 거절한다. 키를 받는 CLI 옵션·설정 파일·로그를 만들지 않았다. 네트워크 예외는 요청 URL을 포함한 원래 오류 대신 제한된 오류 코드로 보고한다.
- 페이지 크기는 1~1000, 요청 간격은 최소 1초이다. pIndex를 증가시키며 list_total_count와 누계를 비교한다. 중도 전체 건수 변경·짧은 페이지·빈 페이지·건수 초과를 확인한다. 429·5xx·연결/JSON 오류 재시도는 최대 3회 추가이며 키 오류로 무인증 수집에 전환하지 않는다.
- 학교 이름 완전 일치·서울교육청·강서구 주소·고등학교·학교코드 유일성, 급식의 학교·기간·식사코드·복합 식별키 중복을 확인한다. 학교×날짜×식사 단위로 보존한다. 요리명·알레르기 번호·줄 구분 태그를 지우지 않는다.
- 학교별 행 수·고유 날짜·식사별 고유 날짜·월별 행 수·빈 값 수를 출력한다. 150일 미만은 경고를 출력하되 실물 검토를 위해 받은 행은 보존한다. 0건 학교는 두 CSV 저장 전에 중단한다.
- 모든 학교 검증 후 두 임시 CSV를 작성하고 각각 배치한다. 기존 파일은 기본적으로 덮어쓰지 않는다. --overwrite를 사용하면 교체할 수 있다. 두 파일 동시 교체의 트랜잭션 보장은 하지 않는다.
- 학생 예제는 수집 스크립트의 전사가 아니라 새로 작성한 Colab 미리보기 코드이다. 자리표시자 KEY만 포함하고 실제 키는 요청 주소·변수 출력에 포함하지 않도록 안내했다. 이번 활동은 표만 사용하므로 그래프·폰트 셀은 추가하지 않았으며 이후 그래프는 koreanize-matplotlib 표준을 따른다.

- --check: 후보 전부의 코드 조회 1회씩과 CHECK_DATES(2024-03-06, 2024-09-04, 2025-01-08)의 급식 각 1회씩. 세 날짜는 수요일이며 실제 급식 운영일이라는 확인은 하지 않았다. FROM=TO·pSize=3·pIndex=1로 하루의 조·중·석을 조회한다. 날짜 범위·식사코드·중복·총 건수 검증을 재사용한다. 요청 간격/재시도는 기존 클라이언트를 사용한다.

## 후속 오류 진단 — HTTP 500 응답 보존

2026-09-09. 사용자가 --check 실행에서 HTTP 500이 발생했다고 보고하고, 전체 응답 본문·인증키를 마스킹한 전체 URL·RESULT.CODE/MESSAGE 출력 추가를 요청했다. 실제 HTTP 응답 본문과 실패 URL은 아직 제공받지 않았다. 최초/이전 후속 기록의 ‘요청 URL 비출력’ 정책은 이번 사용자 요청의 마스킹 출력으로 대체한다.

- 확인한 문제: 기존 HTTPError 분기는 상태코드를 읽은 뒤 error.close()를 호출하고 본문은 읽지 않았다. 현재는 error.read()로 본문 전체를 수신한 뒤 finally에서 닫는다. 각 실패 시도에서 상태·번호·URL·본문·RESULT를 출력하고 기존 재시도 정책으로 진행한다.
- 진단 구현: request.full_url을 키 마스킹 함수에 통과시킨다. 키는 앞뒤 3자만 남기며 6자 이하는 모두 가린다. 본문·메시지에 반사된 키의 원문 및 일반적인 URL/JSON/HTML 표현도 가린다. 본문은 길이 제한 없이 출력한다. 서버 문자셋·UTF-8·CP949 순서로 디코딩하고, 수신 중 끊긴 일부 본문과 빈 본문·응답 미수신을 구분한다.
- RESULT 파싱: JSON 최상위/중첩 head 및 XML RESULT에서 CODE·MESSAGE를 별도 출력한다. HTTP 200의 업무 오류/응답 구조 오류와 JSON 해석 실패도 같은 진단을 제공한다. RESULT가 없는 HTML 등은 원문과 ‘찾을 수 없음’ 안내를 표시한다. 정상적인 INFO-200의 자료 없음 처리는 유지한다.
- 요청 구성 소스 대조: API_BASE=https://open.neis.go.kr/hub/와 schoolInfo/mealServiceDietInfo 서비스명이 사용자 지정 엔드포인트와 일치한다. 공통 KEY·Type=json·pIndex·pSize가 params에서 들어간다. schoolInfo는 SCHUL_NM과 ATPT_OFCDC_SC_CODE=B10을 모두 전달하고, 급식은 --check와 전체 수집 양쪽에서 ATPT_OFCDC_SC_CODE와 조회한 SD_SCHUL_CODE를 전달한다. 모든 요청은 urlencode(params)를 사용한다.
- 학교명: 동양고등학교·명덕고등학교·마포고등학교·대일고등학교·영일고등학교·세현고등학교 6개 정식 명칭을 소스로 확인했다. 코드상 누락이나 약칭은 발견하지 못했으며 서버가 실제로 어떤 요청을 거부했는지는 재실행 출력으로 확인해야 한다.
