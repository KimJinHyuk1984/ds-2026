## 조사 범위와 복사 목록

- 저장소 최상위 목록과 사용자 지정 `source/`를 조사했다. 외부 원본 경로는 지정되지 않았다.
- `source/`의 원본은 PDF 1개다. 별도 PPTX·이미지·압축파일·실습 코드·CSV·노트북은 0개다. 교체 전 PDF의 내장 첨부파일도 0개였다.
- 외부 원본 복사 0개, 압축 해제 0개, 공개 실습 복사 0개. `files/`는 생성하지 않았다.
- PDF 안의 실습 파일명·웹 주소는 안내일 뿐 실제 제공 파일로 세지 않았다. 원문을 실행 가능한 코드나 실습 파일로 복원하지 않았다.
- `.gitignore`에 `/source/`, `/work-temp/`, `.venv/`, `venv/`, `__pycache__/`, `*.pyc`를 추가했다. 기존 `.gitignore`는 없었다.
- 원본을 외부에 업로드하거나 온라인 OCR에 전송하지 않았다. PDF.js 도구만 임시 폴더에 설치하여 로컬에서 사용했다.
