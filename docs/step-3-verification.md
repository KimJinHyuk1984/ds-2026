## 데이터 대조

기존 CSV를 PowerShell `Import-Csv -Encoding UTF8`로 읽기만 했다. 집계 스크립트·Python 코드·폰트 설치를 실행하거나 CSV를 다시 만들지 않았다.

- 353행 × 8열, UTF-8 BOM 확인. 2024-03-01~2025-02-16, 인접 날짜 간격이 모두 1일이다.
- 빈 값: 날짜 0, 요일 0, 공휴일여부 0, 평균기온 0, 최고기온 0, 최저기온 0, 강수량 200, 대여건수 0.
- 평균기온 -9.7~31.8, 최고기온 -6.1~36.4, 최저기온 -12.2~28.2, 강수량 0~128.8, 대여건수 14,293~194,244. 사용자 제공 평균기온 평균 15.0, 대여건수 평균 119,928과 반올림 기준으로 일치한다.
- 공휴일여부가 1인 날짜 19일. 학생 페이지에는 사용자 제공 범위와 평균만 사용했다.
- 학생 페이지에는 강수량 빈 값의 개수와 관찰만 있다. 의미·처리법·처리 코드와 교사용 data/README.md 링크가 없음을 확인했다.

## 코드와 도구 사실의 출처

코드 블록 7개는 이 수업용으로 새로 작성한 Colab 예제이며 외부 실습 파일이나 교재 코드의 전사가 아니다. 웹의 `pre[data-code] > code` 텍스트가 해당 예제의 정본이다. 새 Python 파일·노트북 파일·가짜 출력·샘플 데이터는 생성하지 않았다.

설치와 조작 사실은 Orange·Google Colab·pandas·Matplotlib 공식 문서로 확인했다. 글꼴 경로 `/usr/share/fonts/truetype/nanum/NanumGothic.ttf`는 [Ubuntu fonts-nanum 파일 목록](https://packages.ubuntu.com/en/noble/all/fonts-nanum/filelist)으로 확인했다. Matplotlib addfont 등록은 실행 환경마다 다시 필요하므로 새 런타임에서 재실행하도록 안내한다. 도구 문서 링크는 학생 페이지와 CURRICULUM.md에 기재했다. 설명 확인과 Colab 실제 실행 성공은 구분한다.

## 실행 제한과 다음 확인

- `ENV-STEP3-UI`: CUA getState에서 apps/browsers 목록이 모두 비어 있었다. 브라우저를 통한 화면·복사·발표·모바일 검증을 수행하지 못했다.
- `ENV-STEP3-PY`: 사용자가 제공한 Python311 절대 경로로 --version을 요청했지만 PowerShell에서 실행 파일을 인식하지 못했다. 설치·우회 실행·데이터 스크립트 실행은 하지 않았다. Colab 셀 실행 결과를 만들어 제시하지 않았다.
- 실제 확인 순서: week-01/index.html 열기 → 다운로드 CSV 비교 → Orange3 네 위젯 실행 → Colab 셀 1~4 실행과 한글 확인 → 두 도구의 산점도·변경 실험 비교 → 모바일·테마·발표·복사·공통 UI 확인.
- 홈에서 1주차 카드가 열리고 나머지 14개가 준비 중인지 확인한다. 주차 이동은 현재 이전/다음 모두 비활성이 정상이다. coming URL을 직접 열면 기존 안내가 보여야 한다.
- 2주차 전에 정할 것: NEIS 대상 학교(자기 학교만 또는 비교 학교 포함), 급식 데이터 수집 기간, 인증키 준비·사용 방식. 인증키 값 자체를 저장소나 공개 코드에 넣지 않는 방식으로 구체화한다.
